# 上下文连续性

本文件只用于保护长任务的可恢复状态。它不保存完整聊天记录，也不替代应用自身的对话历史。

## 启用条件

仅在宿主明确显示上下文接近上限或已经压缩、多步骤任务已有不可轻易重建的状态、用户准备跨对话继续，或者任务可能中断且仅靠现有文件无法判断下一步时，建立或更新恢复检查点。

普通聊天、短任务、尚未产生有效进展的任务，以及可直接从文件恢复的工作不创建检查点。不要为了判断是否需要保存而扫描全部聊天或工作区。

## 保存位置

- 具体项目：优先更新项目已有的状态文件，否则使用 `notes\continuity.md`。
- 非项目任务：使用 `<WORKSPACE_ROOT>\Chats\Continuity\YYYY-MM-DD-简短主题.md`。
- 同一任务更新同一份检查点，不按轮次重复创建。

## 最小内容

只记录当前目标和完成标准、已完成与已验证结果、关键决定和约束、重要文件路径、未完成事项、阻塞及下一步。不要复制完整聊天、长篇工具输出、文件正文、无关讨论、失效尝试或任何密码、令牌和密钥。

只在关键里程碑、状态实质变化或上下文即将压缩时更新。恢复时先读检查点，再按其中路径读取仍然必要的少量文件。检查点与当前文件或用户最新要求冲突时，以后两者为准并修正检查点。

任务完成后将状态标记为“已完成”；除非用户要求，不删除历史检查点。
