# 编程任务

在 `<WORKSPACE_ROOT>\Projects\<项目名称>` 内完成新的软件或多文件项目。已有项目在其原目录中工作，不为套用分类而移动项目。

只检查与当前请求有关的文件和依赖；除非定位问题或评估影响确实需要，不扫描无关目录或整个代码库。

把项目的源码、素材、文档、笔记、测试和输出保存在项目内部，并按需要使用 `src`、`assets`、`docs`、`notes`、`tests`、`dist` 或 `output`。

验证强度与改动风险相称。优先运行受影响范围的检查；只有改动范围、失败结果或项目要求证明有必要时，才扩大到完整构建或测试。

完成实现、必要验证和请求中明确要求的修复后再交付，不因第一版已经可查看而提前停止。
