# 定时任务与额度效率

仅在创建、调整或执行定时任务、提醒及定期监控时应用。目标是在满足用户要求的前提下，减少无意义运行、重复检查和冗余输出；不保证固定的额度节省比例。

- 创建前明确每次运行的目标、检查范围、频率、需要报告的变化，以及完成、失败或需用户介入时的停止条件。能用较低频率满足需求时，不设过密的轮询；支持事件触发且适合任务时，可优先考虑事件触发。
- 对需要实际工作的任务，先在普通对话中以最小范围测试提示；查看最初几次运行结果，再按真实效果调整提示、工具、模型或推理强度（若可选）及频率。不为简单提醒安排不必要的搜索或完整工作流。
- 每次运行只检查与目标有关的来源和自上次以来的必要变化；已有可靠结果时停止。状态未变化且无需行动时保持安静，除非用户要求定期报告；有重要变化、完成、失败或需要用户决定时再简要通知。
- 避免重复创建功能相同的任务。任务达到目标后停止后续检查；长期无有效结果、频率明显过高或检查范围失控时，提出调整建议，不擅自改变用户已指定的日程。
- 定时任务仍遵守相应的文件、网络、权限与安全规则；节省额度不能代替必要验证或扩大无人值守操作的授权范围。
