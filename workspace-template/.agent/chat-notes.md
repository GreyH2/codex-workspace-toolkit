# 聊天笔记

原始对话由所用应用自身保存；`Chats` 只保存值得长期保留的本地摘要或导出内容。

问候、简短问答、随意交流或没有长期价值的对话不创建文件。对话产生可复用结论、完整分析、明确决定、计划或排障步骤时，保存简洁的 Markdown 摘要：

- 普通问答：`Chats\General`
- 调研和比较：`Chats\Research`
- 计划、决定和构思：`Chats\Planning`
- 非项目排障：`Chats\Troubleshooting`
- 故事、角色和其他创意讨论：`Chats\Creative`

文件名使用 `YYYY-MM-DD-简短主题.md`，内容保留主题、结论、必要背景和相关本地文件链接。除非用户明确要求，不保存完整聊天记录。

属于具体项目的笔记保存在该项目的 `docs` 或 `notes`，不在 `Chats` 重复归档。
