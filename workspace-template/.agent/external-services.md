# 网络与外部服务操作

适用于搜索互联网、查询实时信息、访问指定网页、下载公开资料，以及登录、上传、发布、发送或修改云端数据、远程仓库和访问权限。

## 只读网络查询

- 用户要求搜索、核实、获取最新信息，或者关键事实可能已经变化时再上网；可靠的当前上下文足够回答时不做无意义搜索。
- 从一次范围明确的查询开始，优先使用与问题直接相关的权威或原始来源。核心事实已有充分依据时停止，不为补充非必要例子或改善措辞继续搜索。
- 用户指定网站、页面或资料时先处理该来源；只有它无法回答核心问题、缺少关键事实或需要交叉验证时才扩大范围。
- 清楚区分网页事实、合理推断和不确定内容；使用网络信息时提供可访问的来源链接。
- 下载内容前确认它与任务直接相关；交付文件按 `file-routing.md` 保存，临时资料不散落在工作区根目录。

## 外部状态变更

- 先确认目标服务、账户、对象、可见范围和预期结果，只处理用户明确放入范围的内容。
- 在本地完成能够预先完成的准备和检查，再执行外部变更；不要因过早询问而阻塞已获授权的安全工作。
- 上传或发布前检查实际文件清单、敏感信息、许可证和公开范围。不要把整个工作区、凭据、私人聊天或无关文件一并上传。
- 用户已明确授权的范围内直接推进；扩大公开范围、添加接收者、改变权限或进行新的对外行为时，先取得相应授权。平台要求的关键确认仍应保留。
- 密码、验证码、密钥和令牌不写入工作区、日志或规则文件；需要人工输入时让用户在对应服务中完成。
- 优先使用当前任务最直接且可靠的接口、连接器或命令，不为同一结果反复切换工具、刷新页面或重复提交。
- 外部操作完成后，使用远程服务中的权威状态核对账户、对象、可见性、版本或提交，并提供可访问链接；未经验证不报告成功。
- 失败时保留安全校验和权限边界，先定位网络、证书、身份验证或服务状态，不用关闭 TLS 验证等宽泛降级方式绕过问题。
